Teams Idle Mouse Jiggler v0.1.7

The usage of this form is basic: roughly every 4 minutes after hitting "Start Jiggling," the program will input both a movement command to your mouse and a keyboard command (Left Shift) directly into the OS.
The form will also unfocus, tap the desktop, and refocus within the span of 1 second while toggled. This replicates desktop activity.
This app is meant to be used while the user is *not* using the computer; it will work fine; however, the mouse jiggling will be disruptive, along with the keyboard input.


**IMPORTANT READ ME**
If you alter the interval at which the interaction happens, ensure that it is under 5 minutes. If Teams goes to idle, it takes more interaction than the app can currently provide to take you out of idle.
